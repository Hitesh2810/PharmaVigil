# 6.1 Introduction

Adverse drug reactions (ADRs) are one of the leading causes of patient morbidity and mortality worldwide. However, not every adverse event experienced by a patient is necessarily caused by the suspected medication. Determining whether a drug is actually responsible for an adverse event is known as **causality assessment**.

Traditionally, causality assessment is performed manually by pharmacovigilance experts using standardized clinical guidelines. This process requires careful evaluation of patient history, drug exposure, dosage, clinical observations, temporal relationships, and previous evidence. Since manual assessment is time-consuming and subject to expert interpretation, machine learning can be used to assist healthcare professionals by providing rapid and consistent causality predictions.

The PharmaVigil AI platform incorporates a dedicated Causality Assessment Model that predicts the likelihood that a reported adverse event was caused by the suspected drug. The model analyzes multiple patient and drug-related factors and classifies each report into predefined causality categories.

The causality prediction module forms the second major machine learning component of the PharmaVigil AI platform and works alongside the Classification and Regression modules.

The prediction assists healthcare professionals in understanding whether the drug is likely responsible for the reported adverse event.

# 6.7 Feature Engineering

Several engineered features improve prediction quality.

### Historical AE Frequency

Represents how frequently similar adverse events have been reported historically for the suspected drug.

This feature provides contextual information and improves causality estimation.

---

### Missing Value Indicators

Two binary variables preserve missing information.

- is_missing_age
- is_missing_dose

Instead of removing incomplete reports, these variables allow the model to learn patterns associated with missing clinical information.

# Multinomial Logistic Regression

Multinomial Logistic Regression is an extension of Logistic Regression designed for multi-class classification problems. It estimates the probability of each causality class using the softmax function and assigns the class with the highest probability.

### Advantages

- Simple and computationally efficient.
- Produces probabilistic predictions.
- Easy to interpret.
- Performs well on structured datasets.
- Suitable for multi-class pharmacovigilance problems.

### Limitations

- Assumes linear decision boundaries.
- Limited ability to model highly nonlinear relationships.
- Performance may decrease for extremely complex datasets.

---

# XGBoost Multi-class Classifier

XGBoost is a gradient boosting algorithm that constructs multiple decision trees sequentially. Each tree attempts to reduce the errors produced by previous trees, resulting in highly accurate predictions.

### Advantages

- Excellent predictive capability.
- Handles nonlinear feature interactions.
- Built-in regularization reduces overfitting.
- Efficient implementation.
- Frequently achieves state-of-the-art performance on structured datasets.

### Limitations

- More computationally intensive.
- Requires careful hyperparameter tuning.
- More complex than Logistic Regression.

# Why Multinomial Logistic Regression Was Selected

Among the evaluated algorithms, Multinomial Logistic Regression was selected because it demonstrated reliable predictive performance while maintaining computational efficiency and interpretability.

The major reasons for selecting this model include:

### 1. Effective Multi-class Classification

The model is specifically designed for predicting multiple output classes such as:

- Certain
- Probable
- Possible
- Unlikely
- Unassessable

making it well suited for pharmacovigilance causality assessment.

### 2. Stable Performance

The model produced stable predictions across the testing dataset while maintaining balanced performance on multiple evaluation metrics.

### 3. Probabilistic Predictions

Unlike many traditional classifiers, Multinomial Logistic Regression predicts the probability associated with each causality category. These probability estimates support more informed clinical decision-making.

### 4. Computational Efficiency

The model trains quickly and performs real-time inference efficiently, making it suitable for deployment in a web-based pharmacovigilance application.

### 5. Explainability

The coefficients generated by Logistic Regression integrate effectively with SHAP LinearExplainer, enabling transparent interpretation of feature contributions.

### 6. Deployment Readiness

The model has a lightweight architecture, resulting in faster loading, reduced memory consumption, and efficient integration with the Flask REST API.
