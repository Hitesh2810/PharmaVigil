# 13.1 Introduction

The PharmaVigil AI platform is a web-based application designed to assist healthcare professionals, pharmacovigilance analysts, researchers, pharmaceutical companies, and students in analyzing adverse drug reactions using Artificial Intelligence. The application provides three machine learning modules, SHAP Explainable AI visualizations, and an AI-powered chatbot to simplify pharmacovigilance analysis.

This user guide explains how to install, access, navigate, and use each feature of the PharmaVigil AI platform.

---

The application is designed for:

- Healthcare Professionals
- Pharmacovigilance Analysts
- Clinical Researchers
- Pharmaceutical Companies
- Regulatory Authorities
- Medical Students
- Researchers
- System Administrators

# 13.4 Starting the Application

## Step 1

Start the Flask backend server.

```
python app.py
```

---

## Step 2

Start the React frontend.

```
npm install
npm start
```

---

## Step 3

Open the application in your web browser.

```
http://localhost:3000
```

The homepage of the PharmaVigil AI platform will appear.

# 13.6 Classification Module

The Classification Module predicts whether an adverse drug reaction is classified as:

- Serious
- Non-Serious

### Steps

1. Open the Classification page.
2. Enter the required patient information.
3. Provide drug details.
4. Enter dosage information.
5. Enter country and reporter information.
6. Click **Predict**.

The system displays:

- Prediction Result
- Confidence Score
- SHAP Explanation

---

# 13.7 Causality Assessment Module

The Causality Module predicts the relationship between the suspected drug and the adverse event.

Possible prediction categories include:

- Certain
- Probable
- Possible
- Unlikely
- Unassessable

### Steps

1. Open the Causality page.
2. Enter patient details.
3. Enter drug information.
4. Provide historical adverse event frequency.
5. Click **Predict**.

The prediction is displayed together with SHAP explanations.

---

# 13.8 Regression Module

The Regression Module predicts the expected adverse event reporting count.

### Steps

1. Open the Regression page.
2. Enter the required forecasting inputs.
3. Click **Predict**.

The system displays:

- Predicted Adverse Event Count
- Forecast Graph
- SHAP Explanation

---

# 13.9 SHAP Explainability

After every prediction, SHAP visualizations explain how each feature influenced the model's output.

Available visualizations include:

- Summary Plot
- Bar Plot
- Beeswarm Plot
- Waterfall Plot
- Force Plot
- Decision Plot

Users can analyze these plots to better understand the AI model's reasoning.

# 13.15 Troubleshooting

## Backend Not Running

Ensure the Flask server is started before opening the frontend.

---

## Frontend Not Loading

Verify that the React development server is running.

---

## Prediction Failed

Check:

- Internet connection (for AI Assistant).
- Backend server status.
- Input values.
- Required model files.

---

## AI Assistant Not Responding

Verify:

- Gemini API key configuration.
- Internet connectivity.
- Backend API availability.

# 13.16 Frequently Asked Questions

### Q1. What does the Classification Module predict?

It predicts whether an adverse drug reaction is classified as Serious or Non-Serious.

---

### Q2. What is the purpose of the Causality Module?

It predicts the likelihood that the suspected drug caused the reported adverse event.

---

### Q3. What does the Regression Module do?

It predicts future adverse event reporting counts based on historical data.

---

### Q4. Why are SHAP explanations displayed?

SHAP explains how each input feature influenced the AI model's prediction, improving transparency and interpretability.

---

### Q5. Can I ask pharmacovigilance questions through the AI Assistant?

Yes. The Gemini-powered AI Assistant can answer questions related to pharmacovigilance concepts, machine learning predictions, and application usage.
