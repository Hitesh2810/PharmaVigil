# 5.1 Introduction

Classification is one of the most important supervised machine learning techniques used to categorize observations into predefined classes based on historical patterns. In the PharmaVigil AI project, the Classification Model predicts the seriousness of an adverse drug event using patient demographics, drug information, dosage details, reporting characteristics, and historical adverse event frequency.

The primary objective of the classification model is to assist pharmacovigilance professionals in identifying potentially serious adverse drug reactions quickly and consistently. Early identification of serious adverse events enables healthcare providers and regulatory agencies to prioritize investigations, improve patient safety, and support informed clinical decision-making.

Unlike traditional manual review systems, the developed classification module automatically analyzes multiple patient and drug-related factors to estimate whether an adverse event should be categorized as **Serious** or **Non-Serious**.

The classification pipeline forms the first predictive component of the PharmaVigil AI platform and is integrated with SHAP explainability, visualization dashboards, and REST APIs.

---

# 5.9 Machine Learning Algorithms

Three supervised learning algorithms were implemented and compared.

## Logistic Regression

Logistic Regression is a linear classification algorithm widely used for binary classification problems.

Advantages:

- Simple.
- Fast.
- Easy to interpret.
- Low computational cost.

Limitations:

- Assumes linear decision boundary.
- Limited ability to capture complex relationships.

---

## Random Forest

Random Forest is an ensemble learning algorithm consisting of multiple decision trees.

Each tree learns different patterns from randomly selected subsets of data.

Final predictions are obtained through majority voting.

Advantages:

- High accuracy.
- Handles nonlinear relationships.
- Resistant to overfitting.
- Robust to noisy data.
- Provides feature importance.

---

## XGBoost

Extreme Gradient Boosting (XGBoost) is an advanced ensemble boosting algorithm.

It sequentially builds decision trees while correcting errors made by previous trees.

Advantages:

- Excellent predictive performance.
- Handles complex relationships.
- Regularization reduces overfitting.
- Efficient implementation.

Limitations:

- Higher computational cost.
- More hyperparameters.

# 5.11 Model Evaluation

Several evaluation metrics were used to compare model performance.

## Accuracy

Measures the percentage of correctly classified samples.

Higher accuracy indicates better overall performance.

---

## Precision

Measures the proportion of predicted serious events that were actually serious.

Higher precision reduces false positives.

---

## Recall

Measures the proportion of actual serious events correctly identified.

Higher recall minimizes missed serious cases.

---

## F1 Score

F1 Score combines precision and recall into a single metric.

It provides balanced evaluation when class distributions differ.

---

## ROC Curve

Receiver Operating Characteristic (ROC) curves compare true positive rate and false positive rate across different thresholds.

A model with a larger Area Under the Curve (AUC) generally demonstrates better discrimination capability.

---

## Confusion Matrix

The confusion matrix summarizes prediction performance.

It contains:

- True Positives
- True Negatives
- False Positives
- False Negatives

The confusion matrix helps identify specific classification errors.

# Logistic Regression

Logistic Regression is a linear supervised learning algorithm commonly used for binary classification problems. It estimates the probability that an input sample belongs to a particular class using the logistic (sigmoid) function.

### Advantages

- Simple and easy to implement.
- Fast training and prediction.
- Computationally efficient.
- Easy to interpret.
- Works well when data is linearly separable.

### Limitations

- Assumes a linear relationship between features and the target.
- Cannot effectively model complex nonlinear interactions.
- Performance decreases when the dataset contains highly complex decision boundaries.

---

# Random Forest Classifier

Random Forest is an ensemble learning algorithm that combines multiple decision trees to produce a final prediction. Each tree is trained using different subsets of the training data and features, reducing variance and improving generalization.

### Advantages

- Handles nonlinear relationships effectively.
- Resistant to overfitting.
- Performs well on mixed numerical and categorical data.
- Robust against noisy datasets.
- Provides feature importance scores.
- Suitable for healthcare prediction problems.

### Limitations

- Higher computational cost than Logistic Regression.
- Larger model size.
- Less interpretable than linear models.

---

# XGBoost Classifier

Extreme Gradient Boosting (XGBoost) is a boosting-based ensemble learning algorithm. Instead of building independent trees, XGBoost constructs trees sequentially, where each new tree attempts to correct the errors made by previous trees.

### Advantages

- Very high predictive accuracy.
- Excellent handling of nonlinear relationships.
- Built-in regularization reduces overfitting.
- Efficient memory utilization.
- Supports feature importance analysis.
- Frequently achieves state-of-the-art performance.

### Limitations

- More computationally intensive.
- Requires hyperparameter tuning.
- More complex to understand than Logistic Regression.

# 5.14 Why Random Forest Was Selected

Among the three evaluated algorithms, the Random Forest Classifier was chosen because it provided the best overall balance between predictive performance, robustness, and generalization on the pharmacovigilance dataset.

The key reasons for selecting Random Forest are:

### 1. High Predictive Performance

Random Forest achieved strong performance across the evaluation metrics, demonstrating its ability to accurately distinguish between **Serious** and **Non-Serious** adverse drug events.

### 2. Ability to Handle Non-Linear Relationships

Pharmacovigilance data contains complex relationships among patient age, drug information, dosage, reporting country, manufacturing batch, and historical adverse event frequency. Random Forest effectively captures these nonlinear interactions without requiring complex feature transformations.

### 3. Reduced Overfitting

Unlike a single decision tree, Random Forest combines predictions from multiple decision trees. This ensemble approach minimizes overfitting and improves the model's ability to generalize to unseen adverse event reports.

### 4. Robustness to Noisy Data

Healthcare datasets often contain incomplete or noisy observations. Random Forest is relatively insensitive to such irregularities, making it well suited for pharmacovigilance applications.

### 5. Support for Mixed Feature Types

The dataset includes both numerical and categorical variables. After preprocessing and label encoding, Random Forest efficiently processes both feature types without requiring extensive normalization.

### 6. Feature Importance Analysis

Random Forest provides estimates of feature importance, allowing researchers to identify which variables contribute most to the prediction of adverse event seriousness. This complements the SHAP explainability module implemented in the project.

### 7. Reliable Generalization

The ensemble learning approach produces stable predictions for previously unseen data, making the model suitable for deployment in real-world pharmacovigilance systems.

# 5.16 Deployment of the Final Model

After model selection, the trained Random Forest model was exported using the Joblib library and stored as:

```

classification_model.pkl

```

During application startup, the Flask backend automatically loads:

- classification_model.pkl
- feature_columns.pkl
- Label encoders
- SHAP explainer

When a user submits patient and drug information through the React interface, the backend preprocesses the input, applies the same feature encoding used during training, and uses the Random Forest model to predict whether the adverse event is **Serious** or **Non-Serious**. The prediction, along with SHAP-based feature explanations, is then returned to the frontend and displayed to the user.
