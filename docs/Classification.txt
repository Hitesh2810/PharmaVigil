# **PART 1: Machine Learning Models for Adverse Event Severity Prediction**

## 4.1 Introduction

After completing data preprocessing, feature selection, and dataset splitting, the next stage of the project involved developing machine learning models capable of predicting the severity of adverse drug events. Machine learning was selected because adverse event datasets contain numerous variables that interact in complex ways. Traditional statistical approaches often struggle to capture these interactions, whereas machine learning models can automatically learn relationships between multiple input features and produce accurate predictions. By learning patterns from historical adverse event reports, these models can assist healthcare professionals in identifying potentially serious adverse reactions at an early stage.

To evaluate different modelling approaches, three supervised machine learning algorithms were implemented:

* Logistic Regression
* Random Forest
* XGBoost (Extreme Gradient Boosting)

These algorithms were selected because they represent different learning methodologies. Logistic Regression serves as a simple linear baseline model, Random Forest introduces ensemble learning through multiple decision trees, and XGBoost employs gradient boosting to improve predictive performance. Comparing these models provides valuable insights into how different machine learning techniques handle healthcare data and helps identify the most suitable model for adverse event severity prediction.

# 4.2 Logistic Regression

## Overview

The first predictive model implemented in this project was Logistic Regression. It is one of the most widely used supervised machine learning algorithms for classification problems. Unlike linear regression, which predicts continuous numerical values, Logistic Regression predicts the probability that a data instance belongs to a particular class.

In this project, Logistic Regression was used as the baseline classification model. Establishing a baseline is important because it provides a reference against which more advanced algorithms can be compared. Although Logistic Regression is relatively simple, it offers good interpretability and performs well when the relationship between features and the target variable is approximately linear.

The model attempts to learn how different patient characteristics, drug information, and reaction-related variables influence the likelihood of an adverse event being classified into a specific severity category.

---

## Why Logistic Regression was Selected

Logistic Regression was chosen because it offers several advantages during the initial stages of model development.

First, it is computationally efficient and can be trained quickly even on moderately large datasets. This makes it suitable for establishing an initial benchmark.

Second, Logistic Regression produces probabilistic outputs, allowing each prediction to be associated with a confidence score. Such probabilities can be useful in healthcare applications where uncertainty must be considered.

Third, the model is easy to interpret. Each feature contributes positively or negatively toward the prediction, enabling researchers to understand how different variables influence adverse event severity.

Finally, Logistic Regression serves as an excellent comparison point for more sophisticated ensemble algorithms such as Random Forest and XGBoost.

---

## Working Principle

Logistic Regression learns relationships between input variables and the target class by estimating the probability that a particular observation belongs to each category.

Instead of fitting a straight line, Logistic Regression uses the logistic (sigmoid) function to transform model outputs into probabilities ranging from 0 to 1. During training, the algorithm repeatedly adjusts its internal coefficients to minimize prediction error across the training dataset.

For every adverse event record, the model considers all available input features simultaneously. Features such as patient age, sex, drug characteristics, reaction type, and reporting information collectively influence the predicted probability of the event being classified as serious or non-serious.

Once the model has completed training, it can estimate the probability for previously unseen records and assign the most likely severity class.

---

## Model Training

The dataset had already been divided into training and testing subsets using an 80:20 split. Approximately eighty percent of the data was used for learning while the remaining twenty percent was reserved for performance evaluation.

During training, the Logistic Regression algorithm examined thousands of adverse event records and identified statistical relationships between predictor variables and the target class.

The notebook configured the model with an increased maximum iteration value to ensure convergence. This prevents optimization from stopping before the model reaches a stable solution, particularly when working with datasets containing numerous encoded categorical variables.

After training, the model generated predictions for the unseen testing dataset.

---

## Performance Interpretation

Following prediction, the model's performance was evaluated using multiple classification metrics, including Accuracy, Precision, Recall, and F1-score.

The Logistic Regression model demonstrated that meaningful predictive patterns exist within the adverse event dataset. However, because Logistic Regression assumes approximately linear relationships between features and the target variable, its predictive capability is naturally limited when compared to more advanced ensemble learning methods.

Healthcare datasets frequently contain complex nonlinear interactions among patient characteristics, medications, and adverse reactions. Logistic Regression cannot effectively capture these intricate dependencies, resulting in comparatively lower predictive performance.

Nevertheless, the model successfully established a strong baseline for evaluating subsequent machine learning algorithms.

---

## Strengths

The major strengths of Logistic Regression include its simplicity, fast training time, ease of implementation, and interpretability. Since healthcare applications often require transparency, Logistic Regression provides an understandable decision-making process.

Its probabilistic predictions are also valuable because clinicians can assess confidence levels rather than relying solely on categorical outputs.

---

## Limitations

Despite its advantages, Logistic Regression has several limitations.

It assumes a linear relationship between predictor variables and the target class.

It struggles to capture nonlinear feature interactions.

Its predictive performance decreases when numerous correlated variables are present.

Complex healthcare datasets involving drug interactions, patient history, and multiple clinical variables often require more flexible algorithms capable of learning nonlinear decision boundaries.

These limitations motivated the use of Random Forest and XGBoost in the later stages of the project.

# 4.3 Random Forest

## Overview

After evaluating Logistic Regression, the project introduced Random Forest as the second predictive model. Random Forest is an ensemble learning algorithm that combines multiple decision trees to produce a single, more accurate prediction.

Unlike Logistic Regression, which constructs a single mathematical model, Random Forest builds hundreds of independent decision trees using different subsets of the training data. The final prediction is determined through majority voting among all trees.

This ensemble strategy significantly improves prediction accuracy while reducing the risk of overfitting.

---

## Why Random Forest was Selected

Random Forest was selected because adverse event datasets contain numerous categorical and numerical variables that interact in nonlinear ways.

Decision trees are naturally capable of learning nonlinear decision boundaries. However, a single decision tree is highly sensitive to training data and may overfit.

Random Forest addresses this problem by constructing many decision trees instead of relying on only one. Since every tree observes slightly different training samples and feature subsets, prediction errors made by individual trees tend to cancel each other.

As a result, Random Forest generally provides better accuracy, improved robustness, and greater generalization ability than individual decision trees.

---

## Working Principle

Random Forest operates through two important concepts:

**Bootstrap Sampling**

Each decision tree is trained using a randomly selected subset of the original training dataset.

Different trees therefore learn slightly different decision rules.

**Feature Randomization**

Instead of considering every feature while making each split, Random Forest randomly selects a subset of available features.

This increases diversity among trees and reduces correlation between them.

Finally, all trees independently classify each adverse event record, and the majority vote determines the final prediction.

This collaborative decision-making process significantly improves prediction reliability.

---

## Model Training

The notebook configured the Random Forest classifier using 100 decision trees.

During training, every tree independently analyzed relationships between patient demographics, drug information, adverse reactions, reporting characteristics, and severity labels.

Because each tree learned different decision boundaries, the overall ensemble became capable of modelling highly complex relationships that Logistic Regression could not capture.

---

## Performance Interpretation

Random Forest generally produced better predictive performance than Logistic Regression.

The improvement occurred because Random Forest effectively captured nonlinear relationships among predictor variables.

Healthcare datasets often include interactions between multiple patient characteristics and medications. Random Forest naturally models these interactions without requiring manual feature engineering.

The feature importance generated by Random Forest also provided valuable insight into which variables contributed most strongly to adverse event severity prediction.

This interpretability made Random Forest an excellent intermediate model before introducing XGBoost.

---

## Advantages

Random Forest offers numerous advantages for healthcare prediction problems.

It handles both categorical and numerical variables effectively.

It is resistant to overfitting due to ensemble averaging.

It can automatically identify complex feature interactions.

It provides feature importance scores that improve model interpretability.

It performs well even when datasets contain missing values or noisy observations.

---

## Limitations

Although Random Forest significantly improves prediction accuracy, it also has limitations.

Training multiple decision trees requires more computational resources.

Prediction time is slower than simpler models because many trees participate in each prediction.

Feature importance values indicate overall influence but do not explain how individual features affect specific predictions.

For this reason, additional explainability techniques such as SHAP were later incorporated into the project.

# 4.4 XGBoost (Extreme Gradient Boosting)

## Overview

The final machine learning algorithm implemented in this project was XGBoost, one of the most powerful gradient boosting algorithms available for structured tabular datasets.

XGBoost has become a preferred algorithm in both academic research and industrial machine learning because it consistently achieves high predictive performance while maintaining computational efficiency.

Unlike Random Forest, which trains decision trees independently, XGBoost constructs trees sequentially. Each new tree is specifically designed to correct the mistakes made by previous trees.

This iterative error correction mechanism enables XGBoost to produce highly accurate predictive models.

---

## Why XGBoost was Selected

The primary objective of this project was to maximize prediction accuracy while maintaining reliable generalization on unseen adverse event records.

XGBoost was selected because it offers several advantages over traditional machine learning algorithms.

It effectively models complex nonlinear relationships.

It incorporates regularization techniques that reduce overfitting.

It efficiently handles large structured datasets.

It automatically focuses learning on difficult observations that previous trees classified incorrectly.

These characteristics make XGBoost particularly suitable for adverse event severity prediction, where interactions among drugs, patient demographics, and reactions can be highly complex.

---

## Working Principle

XGBoost builds decision trees sequentially.

The first tree makes an initial prediction.

Errors produced by the first tree are calculated.

The second tree is trained specifically to reduce those errors.

The process continues, with each subsequent tree correcting mistakes made by all previous trees.

Instead of treating every observation equally throughout training, XGBoost gradually concentrates on difficult-to-classify records.

Consequently, prediction accuracy improves after each boosting iteration.

---

## Model Training

Within the notebook, the XGBoost classifier was trained using the prepared feature matrix and target labels.

The model learned complex interactions among encoded patient information, drug-related variables, and adverse reaction characteristics.

Following training, predictions were generated for the testing dataset, and evaluation metrics were calculated.

These metrics were later compared with Logistic Regression and Random Forest to determine the most suitable model.

---

Three supervised machine learning algorithms—Logistic Regression, Random Forest, and XGBoost—were implemented and evaluated for adverse event severity prediction. Each algorithm contributed differently to the analysis and demonstrated unique strengths and limitations.

PART 2: Model Performance Evaluation and Interpretation
5.1 Introduction

After training the Logistic Regression, Random Forest, and XGBoost models, the next phase of the project focused on evaluating their predictive performance. Model evaluation is a crucial step in any machine learning project because it determines how effectively a trained model can classify unseen data. A model that performs well on training data but fails on new data cannot be considered reliable for practical healthcare applications.

In this project, multiple evaluation metrics were employed to assess the effectiveness of each classifier. Instead of relying solely on prediction accuracy, additional metrics such as Precision, Recall, F1-Score, Confusion Matrix, Receiver Operating Characteristic (ROC) Curve, Area Under the Curve (AUC), and Feature Importance were analyzed. These evaluation techniques provide a comprehensive understanding of the strengths and weaknesses of each model and help identify the most suitable algorithm for adverse event severity prediction.

The evaluation process also ensured that the selected model not only achieved high predictive accuracy but also demonstrated consistent performance across different severity classes. Since healthcare applications require reliable and interpretable predictions, using multiple evaluation metrics helps validate the robustness of the developed machine learning system.

5.2 Accuracy

Accuracy is one of the most commonly used evaluation metrics in classification problems. It measures the proportion of correctly classified observations among the total number of observations in the testing dataset. In simple terms, accuracy indicates how often the model makes correct predictions.

For adverse event severity prediction, accuracy represents the percentage of adverse event reports that were assigned to the correct severity category by the machine learning model. A higher accuracy value indicates better predictive performance.

Although accuracy provides an overall measure of model performance, it should not be considered the only evaluation metric, particularly when dealing with healthcare datasets. Medical datasets often contain imbalanced class distributions, where one severity category may contain significantly more observations than another. In such situations, a model may achieve high accuracy simply by predicting the majority class while failing to correctly identify minority cases.

Therefore, while accuracy serves as an important initial performance indicator, additional evaluation metrics are necessary to obtain a complete understanding of model behaviour.

In this project, the Random Forest model achieved the highest prediction accuracy among all three implemented algorithms. This indicates that Random Forest correctly classified a larger proportion of adverse event reports than Logistic Regression and XGBoost, making it the most effective model for this classification task.

5.3 Precision

Precision measures the proportion of predicted positive observations that are actually correct. It evaluates the reliability of positive predictions generated by the model.

In healthcare applications, precision is particularly important because false positive predictions may lead to unnecessary clinical investigations, additional medical procedures, or inappropriate allocation of healthcare resources.

A model with high precision ensures that when it predicts a serious adverse event, the prediction is highly likely to be correct. This increases the confidence of healthcare professionals in the system's recommendations.

The Random Forest model demonstrated superior precision compared to the other machine learning algorithms. This indicates that it produced fewer false positive classifications and generated more reliable predictions for adverse event severity.

High precision is especially valuable in pharmacovigilance because it minimizes unnecessary concern regarding drug safety while maintaining confidence in the identified serious adverse reactions.

5.4 Recall

Recall measures the ability of a machine learning model to identify all actual positive cases within the dataset. It evaluates how effectively the classifier detects serious adverse events without missing important cases.

In adverse event severity prediction, recall is extremely important because failing to identify a serious adverse drug reaction may delay clinical intervention and negatively affect patient safety.

A high recall value indicates that the model successfully identifies most serious adverse events present in the dataset while minimizing false negatives.

The Random Forest model demonstrated strong recall performance, indicating that it effectively detected serious adverse events while reducing the number of missed cases. This characteristic makes the model particularly suitable for healthcare applications where identifying high-risk patients is more important than simply maximizing overall accuracy.

5.5 F1-Score

The F1-Score provides a balanced evaluation by combining both Precision and Recall into a single performance metric. It is particularly useful when evaluating classification models on datasets where both false positives and false negatives must be minimized.

Healthcare datasets often require a balance between correctly identifying serious adverse events and avoiding unnecessary false alarms. The F1-Score reflects this balance by considering both aspects simultaneously.

Among the evaluated machine learning models, Random Forest achieved the highest F1-Score, demonstrating its ability to maintain both high precision and high recall. This indicates that the model produced consistent and reliable predictions across different severity categories.

The superior F1-Score further confirmed the suitability of Random Forest for adverse event severity prediction.

5.6 Confusion Matrix

The Confusion Matrix provides a detailed summary of classification performance by comparing actual class labels with predicted class labels. Unlike accuracy, which only reports the overall percentage of correct predictions, the Confusion Matrix identifies the specific types of prediction errors made by the model.

Each row of the matrix represents the actual class, while each column represents the predicted class. The diagonal elements correspond to correctly classified observations, whereas the off-diagonal elements represent misclassifications.

For this project, the Confusion Matrix revealed that the Random Forest model correctly classified the majority of adverse event reports into their respective severity categories. The large concentration of values along the diagonal indicated strong classification performance.

The relatively small number of off-diagonal entries suggested that the model generated fewer incorrect predictions compared to Logistic Regression and XGBoost.

This visualization provided confidence that the selected model generalized well to unseen data and maintained consistent prediction accuracy across different classes.

5.7 Receiver Operating Characteristic (ROC) Curve

The Receiver Operating Characteristic (ROC) Curve is a graphical evaluation technique used to measure the classification capability of a machine learning model across different decision thresholds.

The ROC Curve plots the True Positive Rate against the False Positive Rate for multiple threshold values. A model that consistently achieves high true positive rates while maintaining low false positive rates produces a curve closer to the upper-left corner of the graph.

A classifier with poor predictive capability generates a ROC curve close to the diagonal reference line, indicating that its predictions are nearly equivalent to random guessing.

In this project, ROC curves were generated for all implemented machine learning algorithms to compare their ability to distinguish between adverse event severity classes.

The ROC Curve corresponding to the Random Forest classifier demonstrated superior separation capability, indicating that it achieved better discrimination between different severity categories than Logistic Regression and XGBoost.

5.8 Area Under the Curve (AUC)

The Area Under the ROC Curve (AUC) provides a single numerical measure of classifier performance.

An AUC value closer to one indicates excellent classification capability, whereas values closer to 0.5 indicate random prediction performance.

The AUC score summarizes the model's ability to distinguish between different classes regardless of the selected classification threshold.

Among the evaluated algorithms, Random Forest achieved the highest AUC score, demonstrating superior discriminative capability and confirming its robustness in adverse event severity prediction.

The high AUC value indicates that Random Forest consistently assigned higher prediction probabilities to the correct severity classes than the other machine learning models.

5.9 Feature Importance

One of the advantages of tree-based machine learning algorithms is their ability to estimate feature importance. Feature Importance measures the relative contribution of each input variable to the final prediction.

Unlike Logistic Regression, which assumes linear relationships between variables, Random Forest identifies the most informative features based on how frequently and effectively they are used while constructing decision trees.

The Feature Importance plot generated in this project ranked all predictor variables according to their contribution to adverse event severity prediction.

Variables with higher importance scores had a greater influence on the model's decision-making process, while variables with lower scores contributed less to the final predictions.

This analysis provided valuable insight into which patient characteristics, drug information, and reaction-related attributes were most relevant for predicting adverse event severity.

The identified important features formed the basis for the explainability analysis performed using SHAP in the subsequent phase of the project.

5.10 Comparative Performance Analysis

The performance of Logistic Regression, Random Forest, and XGBoost was compared using all evaluation metrics.

Logistic Regression established a useful baseline model but demonstrated lower predictive performance because of its inability to capture complex nonlinear relationships present in the adverse event dataset.
